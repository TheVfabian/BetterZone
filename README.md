# BetterZone
BetterZone is a mod for the [rec.zone](https://rec.zone/game) game and a custom server made using the ~~Zone Uni~~ **BetterZone API** by **[teco256](https://github.com/teco256)**, The **API** can be found **~~[here](https://github.com/teco256/Zone-Uni)~~** in the **[`/server`](https://github.com/TheVfabian/BetterZone/tree/main/server)** folder. We hope to bring custom **QOL plugins, themes, and more.**
