# BetterZone
BetterZone is a mod for the rec.zone game and a custom server made using the Zone Uni api by Teco256, The api can be found [here](https://github.com/teco256/Zone-Uni). We hope to bring custom QOL plugins, themes, and more.

# What is currently being worked on
> Loading screen 
> Escape menu
> Custom server
